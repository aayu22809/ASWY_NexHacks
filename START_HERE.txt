STEP 1: Run the comprehensive test
------------------------------------
python3 run_all_tests.py

This will show you:
- If pyrealsense2 is working
- If camera is detected
- What needs to be fixed

STEP 2: If camera not detected
------------------------------------
The test will tell you what's missing. Common fixes:

1. Connect camera to USB 3.0 port (blue connector)
2. Install udev rules:
   sudo cp /mnt/ssd/librealsense/config/99-realsense-libusb.rules /etc/udev/rules.d/
   sudo udevadm control --reload-rules && sudo udevadm trigger

3. Add user to plugdev group:
   sudo usermod -aG plugdev $USER
   # Then log out and log back in

4. Unplug and replug camera

5. Run test again:
   python3 run_all_tests.py
